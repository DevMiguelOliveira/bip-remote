# Ameaças prioritárias

| Ameaça | Mitigação de fundação |
| --- | --- |
| Uso de código de identificação como senha | Identidade criptográfica individual e revogável |
| Operador sem escopo acessa Host | Autorização por organização e unidade |
| UI executa ação privilegiada diretamente | Serviço separado com IPC autenticado |
| Sessão não pode ser investigada | Auditoria append-oriented com ator e resultado |
| Credencial vazada continua válida | Revogação e rotação previstas no modelo |
| Atualização maliciosa do Host | Pacotes assinados e verificação obrigatória |
