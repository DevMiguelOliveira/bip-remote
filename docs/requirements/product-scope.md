# Escopo inicial

## Incluído na fundação

- Organização de monorepo e responsabilidades por módulo.
- Skeleton executável de backend Go.
- Skeleton compilável de Host e serviço Rust.
- Shell desktop Tauri 2, React e TypeScript.
- Contrato OpenAPI v1 e schemas de eventos.
- Modelo inicial PostgreSQL para organizações, unidades, operadores, hosts, sessões e auditoria.
- Regras de segurança, governança e CI.

## Fora do escopo

- Captura e transmissão de tela.
- Controle de mouse e teclado.
- Execução remota de comandos.
- Transferência de arquivos e clipboard.
- Autenticação de produção e integração com provedor de identidade.
- Provisionamento de infraestrutura de produção.
